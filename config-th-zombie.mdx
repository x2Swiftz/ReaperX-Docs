### ✅ ก่อนเริ่มต้นใช้งาน

สคริปต์มันออโต้เลือกโหมดความยากให้ที่สุดที่เราเข้าได้อยู่แล้ว และถ้ายังไม่ปลดมันจะยังไม่เข้าไป และเนื่องจากพึ่งเปิดตัวสคริปต์ได้ไม่นาน ยังไม่มีการยืนยันว่า ฟาร์ม 1 วันได้กี่เพชรกันแน่

### ⚠️ Reset at Wave

จะให้รีเซ็ตตัวละคร ตอนที่เวฟเท่าไหร่ แล้วแต่จะปรับเลย

### 🏹 Buy Weapons

จะให้รหัสไก่ตันซื้ออาวุธอะไรบ้าง แล้วแต่จะปรับเลย

### 🛡️ Buy Classes

จะให้รหัสไก่ตันซื้อคลาสอะไรไว้บ้าง แล้วแต่จะปรับเลย

```python
getgenv().Configs = {
    ['Reset at Wave'] = 100,
    ['Buy Weapon'] = {
        ['Revolver'] = true,
        ['DualPistols'] = true,
        ['SMG'] = true,
        ['CombatShotgun'] = true,
        ['BurstRifle'] =  true,
        ['AK47'] =  true,
        ['Sniper'] = true,
        ['TommyGun'] = true,
        ['HeavyRifle'] = true,
        ['Flamethrower'] = true,
        ['GrenadeLauncher'] = true,
        ['GumdropBlaster'] = true,
        ['ArticStriker'] = true,
        ['WorldEnder'] = true,
    },
    ['Buy Classes'] = {
        ['Medic'] = true,
        ['Marksman'] = true,
        ['Engineer'] = true,
        ['Ninja'] = true,
        ['Demolitionist'] = true,
        ['Tactician'] = true,
        ['Bastion'] = true,
        ['Necromancer'] = true,
    },
    ['Performance'] = {
        ['FPS Lock'] = {
            ['Enabled'] = false,
            ['FPS'] = 15,
        },
    },
}
```

<Warning>
  ควรเปิดไก่ตันด้วยตัวรันคอมเท่านั้น ไม่ควรใช้แอพจำลอง หรือพวกมือถือในการเปิดไก่ตัน
</Warning>
