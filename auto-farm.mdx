### ✅ Start From Level 1

Go to the **Lobby** tab and enable both `Select Slot` and `Auto Select Slot` first.\
This helps the script choose the correct character for farming.

<Tip>
  You can enter a Private Server code to get an extra \+5% EXP, GOLD, and LUCK bonus.
</Tip>

If you use an auto rejoin program and Roblox crashes or disconnects, it will automatically rejoin and select your character for you right away when entering the game. Super easy and stress-free — no need to wake up and reopen everything again.

Now, how do you make it enter stages automatically?

Enable `Auto Select Boost Mission` so it joins the current **Boost Rewards** stage automatically.

<Tip>
  Recommend enabling every Modifier option to make your farming faster.
</Tip>

Also enable `Auto Select Best Grade` so it picks the highest difficulty your account can enter. As your level gets higher, it will automatically join harder missions over time, but...

### 🔄 How Do I Make It Move to Harder Stages?

Set `Current Retry` to any number you want.\
Personally, I use **5**.

That means after replaying the stage 5 times, the script will return to the Lobby and switch to a harder stage or another stage that currently has Boost Rewards.

Most importantly, don’t forget to enable `Auto Leave When Retry Complete` or this feature will not work.

### ⚙️ After Everything Is Ready

Go to the `Auto Farm` tab and enable:

- `Auto Farm`
- `Auto Reload`
- `Auto Refills`

Then, to make it replay forever, make sure to also enable `Auto Retry` so it works together with the `Auto Leave When Retry Complete` feature.

### 🛡️ If You Want Safer Farming

Of course our script is already safe, but I recommend setting **Safe Time** to around **25 seconds**.\
You can lower it if you want.

### 🚀 How to Farm Faster

I recommend enabling both:

- `Auto Use Potions`
- `Auto Buy Potion`

This can make your farming around **2x faster**.

Keep in mind that gear cannot be upgraded while inside a Mission.

<Tip>
  I recommend using ODM Blades for farming instead of Thunder Spears, because new accounts usually have very limited Spear ammo.
</Tip>

### 👀 Recommended Setting While Watching the Farm

If you leave the farm running and want to watch the gameplay sometimes, enable `Auto Hide UI` in the `Settings` tab.

This will automatically hide the script menu every time you run the script, so the UI won’t block your screen.

Enabling `White Screen` is recommended because when you minimize Roblox, it helps reduce GPU usage.

Most importantly, if you are running multiple Roblox windows, I recommend setting the `FPS Limit` to **15**.\
I do not recommend going lower than this because it can make farming significantly slower.

If you are only running one Roblox window, setting the FPS Limit to **30** is already enough.
