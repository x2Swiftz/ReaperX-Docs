## Auto Expeditions

ฟังชั่นนี้ กดอันเดียวไม่ต้องเซ็ตอะไรเยอะ คุณสามารถใช้เล่นได้ทั้ง 3 ด่าน และสามารถเล่นระดับความยากระดับ Difficulty 3 ได้ชิวๆ 💀💀💀

#### โดยฟังชั่นนี้หลังจากกดใช้แล้วมันจะ

- ✅ วางตัว / อัปเกรดตัว / ซื้อ Units / ซื้อบัฟ / สุ่มสแตท / ซ่อม Payload อัตโนมัติ (ถ้า HP น้อย)
- ✅ ออโต้เก็บลูก Orb ให้ทันที (ตามภาพที่วงไว้)
- ✅ ออโต้ซื้อบัฟเฉพาะระดับ Mythic เท่านั้น

### 💀 Select Maps / Difficulty

เลือกแมพที่เราจะลง และอีกอันคือเลือกระดับความยากที่เราจะลง โดยสูงสุดอยู่ที่ 3

### 🛒 Select Helpers

สามารถเลือกได้เลย ว่าจะให้ซื้อตัวละครไหนในร้านค้า

### 🃏 Card Priority

เป็นออโต้เลือกการ์ดให้อัตโนมัติ โดยสามารถเลือกลำดับความสำคัญได้ อันไหนอยู่บนสุดก็จะเลือกอันนั้นก่อน
