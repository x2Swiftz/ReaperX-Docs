## ⭐ Tower Placement ⭐

คือฟังชั่นที่เอาไว้ใช้กับตัว `Macro Play` เราทำออกมาให้สำหรับคนที่ขี้เกียจอัดมาโครทุกด่านภายในเกมเช่น คนจะฟาร์ม Challenge / Mastery ซึ่งแน่นอนว่ามันหลายด่าน แต่ ตัวระบบนี้ อัดมาโครด่านไหนก็ได้ด่านเดียว แล้วเอาไปใช้ได้กับทุกด่านเลย

## ✅ ขั้นตอนการใช้งาน

- สร้างไฟล์ อัดมาโครให้เรียบร้อยก่อน จากนั้นเปิด `Macro Play` / `Quick Play`
- จากนั้นให้เปิด `Auto Tower Placement`
- แล้วเลือกกด `Set` เพื่อเลือกด่าน และตำแหน่ง Units ที่ต้องการจะให้วางด้วย

  src="/images/Screenshot-2026-07-28-063450.png"

- Slot 1 = Unit 1 ตามลำดับที่ชี้ไว้เลย แล้วลากไปในจุดที่คุณต้องการเลย
- สามารถสังเกตุได้ง่ายๆ ตามที่เห็นในภาพ ลากในแมพในสคริปต์ก็จะเห็นในด่านด้วย (ต้องอยู่ในด่านนั้นด้วย)

<Info>
  สามารถใช้ Scroll เมาส์ ซูมเข้า/ออกได้ / ล็อค Slot ได้ กันมือลั่นไปโดน แต่ถ้าคุณเซ็ตอะไรครบหมดแล้ว กด Done ปิดไปได้เลยนั่นเอง
</Info>
