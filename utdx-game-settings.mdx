## \
**\[Game Finished\]**

└ สำหรับคนตั้งมาโครเรียบร้อยหมดแล้ว พอเกมจบจะให้ทำอะไรต่อโดยจะมีให้เลือกดังนี้:

```dart
Auto Replay → เล่นด่านนั้นซ้ำ
Auto Next → ไปด่านถัดไป
Auto Back to Lobby → กลับไปหน้า Lobby
```

## **\[Card Picker\]**

└ ออโต้เลือกการ์ดต่างๆ ในโหมด Virtual Realms, Gohan Rift และอื่นๆ

## \
**⭐ สำหรับโหมด Virtual Realms ⭐**

สามารถปรับ Priority หรือก็คือ ลำดับความสำคัญได้ อันไหนอยู่บนสุดก็จะเลือกอันนั้นก่อน ถ้าไม่เข้าใจว่าแต่ละ Blessing อันไหนดี ให้กด 3 จุดอ่านคำอธิบายเอาได้ แต่ถ้าไม่รู้ว่าอันไหนดีบ้างให้ลองศึกษาดูผ่าน YouTube ตามช่องต่างๆเอาเลย
