## 📜 Auto Join Boss Bounty

กดไปแล้วมันก็ออโต้จอยเข้าไปเฉยๆ

<Warning>
  ต้องใช้คู่กับ Tower Placement เท่านั้น ถ้าเซ็ทไว้เรียบร้อยแล้วก็ปล่อยฟาร์มนอนอ้วนชิวๆเลย
</Warning>

## 📜 Auto Reroll Boss

Select Rarity ให้เลือกระดับเอาได้เลย

```rust
1 = Rare
2 = Legendary
3 = Secret
```
